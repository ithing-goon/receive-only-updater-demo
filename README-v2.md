# GitHub 파일 수신기 v0.1.1 — 시스템 인증서 자동 적용

기존 README.md의 구조와 보안 경계는 유지합니다. 이 버전부터 별도의 CA 옵션 입력 없이 다음 명령으로 실행합니다.

```powershell
node updater.mjs
```

updater.mjs는 현재 Node.js가 --use-system-ca를 지원하는지 확인한 뒤 같은 로컬 프로그램을 해당 옵션으로 재실행합니다. Update.ps1 역시 옵션을 자동으로 적용합니다. Node.js 실행 파일은 동일한 경로를 사용하고 셸 명령 문자열은 구성하지 않습니다.

Windows에 등록된 신뢰 인증서와 Node.js 기본 인증서를 사용합니다. 인증서 검증을 끄거나 인증서를 자동 설치하지 않습니다. 사내 CA가 Windows에서 갱신되면 다음 실행에서 시스템 저장소를 사용합니다. CA가 누락되거나 인증서가 만료되면 계속 중단하며, 이 경우에는 조직의 인증서 배포/관리 조치가 필요합니다.

처음 한 번 기존 수신기 대신 이 버전의 파일을 배치해야 합니다. 이 도구는 자기 코드나 공개키를 자동으로 교체하지 않습니다. 배포 ZIP에는 수신기, PowerShell 실행기, 공개키, 문서만 포함됩니다. 외부 서명용 개인키와 게시 도구는 제외합니다.

검증: 외부 Windows PC에서 Node.js v22.23.2로 기존 18개 테스트 통과. CA 옵션을 생략한 직접 실행과 PowerShell 실행기에서 실제 GitHub 응답 검증 및 already-current 확인. 내부망에서는 이전 버전에 --use-system-ca를 지정했을 때 verified가 나왔다고 사용자가 보고했습니다. 새 버전의 내부망 직접 실행은 아직 확인되지 않았습니다.
